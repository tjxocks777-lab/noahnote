# 테스트

```
node --test 'test/*.test.mjs'
```

Node 22 이상이면 설치할 게 없다. 외부 라이브러리를 쓰지 않는다.

## 왜 있나

2026-11-05 이전에는 기기 간 동기화가 "마지막에 올린 쪽이 이김" 방식이어서,
**폰에서 공부한 내용이 PC 동기화 때 통째로 사라지는 사고**가 있었다.
지금은 기준본과 3자 비교로 합치고(`syncMergeAll`), 서버는 `expect=<버전>`일 때만 저장한다.

이 두 가지는 **틀리면 사용자 데이터가 조용히 사라지는** 코드다.
고쳤을 당시에는 한 번만 확인하고 넘어갔는데, 그러면 다음에 손댈 때 안전망이 없다.
그래서 그때 확인한 내용을 저장소에 남겨 둔다.

동기화·합치기 코드를 고쳤으면 **커밋 전에 반드시 돌린다.**

## 파일

| 파일 | 하는 일 |
|---|---|
| `merge.test.mjs` | 합치기 로직 — 양쪽 수정, 삭제 전파, 복습 기록 충돌, 일지, 과목, 순수성, 성능 |
| `sync-api.test.mjs` | 서버 `functions/api/sync.js` — 입력 검사, 조건부 저장(409), 첨부, 저장소 분리 |
| `extract.mjs` | `index.html` 에서 합치기 함수를 떼어내 온다 |
| `fake-kv.mjs` | Cloudflare KV 흉내 (`functions/_lib/kv.js` 가 쓰는 것만) |

## extract.mjs 에 대해

합치기 로직은 아직 `index.html`(7,000줄 넘는 단일 파일) 안에 있다.
앱을 모듈로 쪼개는 건 별개의 큰 작업이라, 그때까지는 소스를 고치지 않고 이 추출기로 테스트를 붙인다.

떼어내는 구간은 `index.html` 의 주석 두 줄 사이다.

```
/* ── 합치기 (순수 함수 ...     ← 여기부터
...
/* ── 서버 통신 ── */           ← 여기까지
```

이 주석을 바꾸거나 함수를 다른 곳으로 옮기면 테스트가 **"찾지 못했어요"로 바로 실패**한다.
낡은 코드를 조용히 검사하는 일은 생기지 않으니, 그때 `extract.mjs` 의 표시를 같이 고치면 된다.

> 앞으로 합치기 로직을 별도 파일(`sync-merge.js` 같은)로 빼면 `extract.mjs` 는 지우고
> 테스트에서 바로 `import` 하면 된다. 그게 자연스러운 첫 분리 지점이다.

`node:vm` 대신 `data:` URL 로 읽어들이는 이유는 `extract.mjs` 주석에 적어 뒀다
(샌드박스는 realm 이 달라서 `deepStrictEqual` 이 거부한다).

## 테스트가 쓸모 있는지 확인한 방법

통과만 하고 깨진 코드를 못 잡으면 의미가 없어서, 일부러 망가뜨려 확인했다.

| 일부러 넣은 고장 | 결과 |
|---|---|
| 합치기에서 "이 기기에만 있는 항목" 루프 제거 | 실패 1건 ✓ |
| 서버 `expect` 조건 검사 무력화 | 실패 2건 ✓ |
| 추출 표시(주석) 변경 | 못 찾았다고 실패 ✓ |
| 복습 기록 승자 판정 뒤집기 | 실패 2건 ✓ |

## 아직 테스트가 없는 곳

여기 있는 건 **데이터가 사라지는 경로**만이다. 아래는 아직 손으로 확인해야 한다.

- 실제 Cloudflare KV 의 지역 간 반영 지연 (가짜 KV 는 즉시 반영된다)
- 실제 폰 ↔ PC 조합, 실제 푸시 수신
- 화면 동작 전반 (복습 출제, 노트 편집기, 마인드맵)
- 스캔 (`functions/api/scan.js`) — API 키가 필요해서 아직 돌려보지 못함
